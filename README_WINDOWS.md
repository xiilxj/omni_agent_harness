# Omni Agent Harness (Windows 独立运行指南)

欢迎使用 **Omni Agent Harness** 工业级智能体交互底座！本项目支持在 Windows 纯原生环境中独立运行，无需安装复杂的 Linux 虚拟机或 Docker。

---

## 🚀 极速上手使用（3 步启动）

### 第一步：环境准备
- 确保您的电脑已安装 **Python 3.10 或更高版本**（[Python 官网下载地址](https://www.python.org/downloads/)）。
- *重要提示*：安装 Python 时，务必勾选 **`Add Python to PATH`**（将 Python 添加到系统环境变量）。

### 第二步：一键启动
- 解压本压缩包到任意文件夹（例如 `D:\Omni_Agent_Harness`）；
- **直接双击运行 `start_windows.bat`**；
- 脚本会自动检查环境、安装依赖，并自动在默认浏览器中弹出控制台页面：
  👉 **`http://127.0.0.1:7890`**

### 第三步：配置您自己的 API Key
- 打开网页后，点击右侧设置抽屉中的 **`Models & API`**；
- 输入您自己的 **DeepSeek API Key**（或 OpenAI / 自建 vLLM 服务地址）；
- 点击保存即可开启全功能自主智能体协作！

## 🛠️ 核心功能特性
1. **💬 上下文精准引用与选择性引用系统**：
   - 自动区分 `> 💬 [引用 用户提问]:` 与 `> 💬 [引用 AI 回答]:`；
   - 支持右键快捷菜单、选中文本浮动胶囊与顶部小图标一键引用，自动插入 Markdown 块引用并展开输入框。
2. **✏️ 模型历史回答行内自主修改与下轮上下文即时替换**：
   - 点击 AI 回答右上角的 `✏️` 小图标即可直接编辑模型输出并保存；
   - **下一轮对话时，大模型接收到的上下文将 100% 以您修改后的内容为准**。
3. **🛑 一键急停与实时穿插纠偏对话机制 (Mid-flight Steer)**：
   - 随时按 `Esc` 毫秒级急停打断模型吐字与工具执行；
   - 任务运行期间输入框不锁死，随时输入指令穿插纠偏与追问，动态调整 Agent 执行方向。
4. **⚡ 全套斜杠快捷指令系统 (Slash Commands)**：
   - 输入 `/` 弹出智能补全菜单（`/goal`, `/grill-me`, `/schedule`, `/browser`, `/teamwork-preview`, `/learn`, `/clear` 等）。
5. **🛡️ 100% 协议级系统提示词注入 & 纯净预设中心**：
   - 初始纯净留白，支持多预设保存、覆盖管理、`Ctrl+S` 快捷热保存与 `[📝 源码编辑]` / `[👁️ 实际透视预览]` 双视图。
6. **🌐 3次指数退避网络重试与 180s 深度思考防超时**：
   - 遇到网络波动自动重试 3 次，从根源杜绝 `network error`。
7. **📏 输入框双向高度动态自适应与瞬间收缩**：
   - 打字/粘贴多行自动展开，删除/发送瞬间收缩回初始单行紧凑状态。
8. **14 大跨平台自动化工具箱**：
   - 原生支持 Windows PowerShell、cmd 终端命令、精确代码搜索替换、AST 语法分析、文件系统探索与网页抓取。
