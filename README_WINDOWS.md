# Omni Agent Harness (Windows 独立运行指南)

欢迎使用 **Omni Agent Harness** 工业级智能体交互底座！本项目支持在 Windows 纯原生环境中独立运行，无需安装复杂的 Linux 虚拟机或 Docker。

---

## 🚀 极速上手使用（3 步启动）

### 第一步：环境准备
- 确保您的电脑已安装 **Python 3.10 或更高版本**（[Python 官网下载地址](https://www.python.org/downloads/)）。
- *重要提示*：安装 Python 时，务必勾选 **`Add Python to PATH`**（将 Python 添加到系统环境变量）。

### 第二步：一键启动
- 解压本压缩包到任意文件夹（例如 `D:\Omni_Agent_Harness`）；
- **直接双击运行 `start_windows.bat`**；
- 脚本会自动检查环境、安装依赖，并自动在默认浏览器中弹出控制台页面：
  👉 **`http://127.0.0.1:7890`**

### 第三步：配置您自己的 API Key
- 打开网页后，点击右侧设置抽屉中的 **`Models & API`**；
- 输入您自己的 **DeepSeek API Key**（或 OpenAI / 自建 vLLM 服务地址）；
- 点击保存即可开启全功能自主智能体协作！

## 🛠️ 核心功能特性（把控制权 100% 彻底交给用户）
1. **✏️ 模型历史回答行内自主修改与下轮上下文即时替换**：
   - 点击 AI 回答右上角的 `✏️` 小图标即可直接编辑模型输出并保存；
   - **下一轮对话时，大模型接收到的上下文将 100% 以您修改后的内容为准**，彻底杜绝幻觉连环污染。
2. **🛑 实时穿插纠偏对话机制 (Mid-flight Steer) 与物理级急停**：
   - 随时按 `Esc` 毫秒级急停打断模型吐字与工具执行；
   - 任务运行期间输入框绝不锁死，随时输入指令穿插纠偏与追问，动态调整 Agent 执行方向。
3. **📱 Telegram 嵌入式全功能远程控制与 Web 双向同步推送**：
   - 支持手机端随时随地下发任务，Web 端耗时任务完成后全自动同步推送到手机 Telegram。
4. **👑 100% 协议级系统提示词三层置顶注入 & 纯净预设中心**：
   - 初始纯净留白，首尾双锚定锁死，支持多预设保存、覆盖管理、`Ctrl+S` 快捷热保存与 `[📝 源码编辑]` / `[👁️ 实际透视预览]` 双视图。
5. **🎲 最高回答词预设库与随机号池引擎 (Master Response Suffix & Random Pool)**：
   - 自动在每轮 AI 回答末尾注入指定签结词并深度融入磁盘会话历史事实，支持号池随机抽取轮换。
6. **🛡️ 思维链拒答实时审计熔断与三阶豁免自愈**：
   - 前 200 字探测拒答倾向毫秒级掐断网络流，节省 90% Token，自动三阶递进豁免重试。
7. **💬 上下文精准选择性引用系统**：
   - 自动区分用户提问与 AI 回答，支持右键快捷菜单、选中文本浮动胶囊与顶部小图标一键引用。
8. **🎯 DSH 官方像素级复刻 Telemetry 仪表盘与实时计费清单**：
   - 实时监控 Tokens、缓存命中数（节省 90% 成本）、吐字速率与精确到分后五位的实时计费。
9. **🌐 跨平台多模型矩阵与 14 大原生工具箱**：
   - 原生支持 Windows PowerShell、cmd 终端命令、精确代码搜索替换与文件系统探索；支持 DeepSeek、Gemini 3.5、OpenAI、Claude、Ollama 等自由切换。
