# Omni Agent Harness (Windows 独立运行指南)

欢迎使用 **Omni Agent Harness** 工业级智能体交互底座！本项目支持在 Windows 纯原生环境中独立运行，无需安装复杂的 Linux 虚拟机或 Docker。

---

## 🚀 极速上手使用（3 步启动）

### 第一步：环境准备
- 确保您的电脑已安装 **Python 3.10 或更高版本**（[Python 官网下载地址](https://www.python.org/downloads/)）。
- *重要提示*：安装 Python 时，务必勾选 **`Add Python to PATH`**（将 Python 添加到系统环境变量）。

### 第二步：一键启动
- 解压本压缩包到任意文件夹（例如 `D:\Omni_Agent_Harness`）；
- **直接双击运行 `start_windows.bat`**；
- 脚本会自动检查环境、安装依赖，并自动在默认浏览器中弹出控制台页面：
  👉 **`http://127.0.0.1:7890`**

### 第三步：配置您自己的 API Key
- 打开网页后，点击右侧设置抽屉中的 **`Models & API`**；
- 输入您自己的 **DeepSeek API Key**（或 OpenAI / 自建 vLLM 服务地址）；
- 点击保存即可开启全功能自主智能体协作！

## 🛠️ 核心功能特性
1. **DSH 4 大模型档位 & 5 档深度推理强度**：
   - 包含 `Flash (极速)`、`Pro (代码重构)`、`Reasoner (数学与深度推演)`、`Vision (图文多模态)`；
   - 支持 5 档真实思考 Token 预算调节（`Off` ~ `Max 32k`）。
2. **纯净自主系统提示词中心**：
   - 初始纯净留白，支持用户完全自主编写、保存多个专属预设、一键热切换与覆盖管理；
   - 具备 `[📝 编辑源码]` 与 `[👁️ 实际透视预览]` 双视图，彻底消除黑盒。
3. **8 大跨平台自动化工具箱**：
   - 原生支持 Windows PowerShell、cmd 终端命令、精确代码搜索替换、文件系统探索与网页抓取。
4. **会话归档与自主重命名**：
   - 完整会话持久化、重命名与归档管理。
